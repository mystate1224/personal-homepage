# 贺晋文的个人主页

面向企业面试与教师交流的个人作品主页，展示深圳大学计算机技术硕士研究生背景、AI 与物联网项目、技能方向、竞赛成果和个人兴趣。

当前展示 5 项经历：寻径 PathFinder 教学智能体、保密阶段的企业智能客服、多维增效 AI 笔记、智能共享停车位、AIoT 手部康复手套。PathFinder 采用重点展示卡片，完整技术与项目自测结果可展开查看；企业项目仅公开概况与进行中状态。

- 网站地址：https://mystate1224.github.io/personal-homepage/
- 仓库地址：https://github.com/mystate1224/personal-homepage
- 技术：HTML、CSS、原生 JavaScript、原创 SVG 技术示意图。
- 无需安装依赖，无构建步骤，无外部字体、图片或脚本服务。

## 文件结构

```text
index.html          页面内容与结构
styles.css          蓝白配色、响应式布局、打印样式
script.js           导航、项目筛选、邮箱复制、阅读位置高亮
assets/             主页与项目的原创 SVG 技术示意图、网站图标
.nojekyll           直接发布静态文件
```

## 本地浏览

直接双击 `index.html` 即可浏览。邮箱复制需要浏览器允许访问剪贴板；在本地文件或受限环境下会提示手动复制。

也可在本目录启动本地静态服务器，然后用浏览器访问：

```sh
python -m http.server 8000
```

## GitHub Pages

使用 `main` 分支根目录作为发布来源：在仓库 Settings → Pages 中选择 Deploy from a branch → main → / (root)。

源代码变更提交并推送后，GitHub Pages 会重新发布。本站所有资源均使用相对路径，适配 `/personal-homepage/` 项目站点路径。

## 内容维护

1. 在 `index.html` 修改个人介绍、项目、获奖与联系方式。
2. 在 `styles.css` 的 `:root` 修改主题颜色；媒体查询控制手机和桌面布局。
3. 项目 `data-categories` 使用 `ai`、`iot`，可同时属于两个方向。
4. 邮箱若变化，需要同时更新 HTML 中的邮件链接以及 `script.js` 中的复制值。
5. 项目图是技术结构示意，不是产品截图。公开成果链接只有在获得真实链接后再添加。

## 已实现的体验

- 桌面导航与手机折叠菜单；支持键盘操作与 Escape 关闭。
- AI / 物联网项目筛选，项目详情原生展开。
- 邮箱直接发送、复制，复制失败时提示手动复制。
- 禁用 JavaScript 后仍保留正文、全部项目、导航和邮件链接。
- 减少动画偏好与 A4 打印样式；打印时展示全部项目。
- 公开页面不含学号、电话号码、住址或原始简历 PDF。

完整实验材料保存在仓库之外的本地目录，避免学号与原始对话进入公开仓库。
