轻量端到端架构

Python FastAPI 分层组织 27 个业务模块；SQLite 启用 WAL，自建 FTS5 trigram 全文检索，不可用时降级为 LIKE。原生 HTML/CSS/JS 实现 10 个页面，零框架、零构建，8 个 Python 依赖即可启动。

规则 + 模型双引擎

所有 AI 能力提供规则兜底，统一返回 engine 标记并显示前端徽标。无 API Key 或断网时仍可完整演示，支持评审现场的网络不确定性。

五路由 RAG 问答

自行实现混合式、图谱式、智能体式、纠错型和多模态五种检索路由，按题型与素材形态自动分流；答案标注资料出处，可跳转原文。

能力画像量化引擎

对标 CEEAA 毕业要求与人社部八项职业核心能力，定义 6 个能力维度。以 Bloom 认知层次加权（记忆、理解 0.6 → 创造 1.5），将作业得分率、知识点命中、答疑提问词与团队参与转化为证据。

结合加权合成、置信度、EMA 衰减（半衰期 90 天）与滞回防抖（±0.15、冷却 14 天），输出主标签和 A/B/C 分层。项目噪声场景测试中，人均结论切换次数由 1.587 次降至 0.271 次。
